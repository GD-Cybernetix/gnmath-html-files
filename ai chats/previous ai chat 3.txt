   current code just has the script floating inside a generic <div

   the placement ID in the div's id.

  The typical Adsterra native banner setup is:

  <div id="container-9e9f96078bb02b26ee2271127f64a418"></div>
  <script async="async" data-cfasync="false" src="//pl29480014.effectivecpmnetwo
  rk.com/9e9f96078bb02b26ee2271127f64a418/invoke.js"></script>

  That container-{placementId} div is what the script targets. Without it, the
  script runs but has nowhere to render the ad — which is exactly why you see
  the social bar (separate script, works independently) but no native banner.
